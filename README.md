# aangan

An architecture, interior, and residential studio web application built with TanStack Start, React 19, Tailwind CSS v4, Framer Motion, Three.js, Leaflet, and Supabase.

## Development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` and fill in your Supabase credentials if testing the consultation form backend.

## Scripts

- `npm run dev` — start the Vite + TanStack Start development server
- `npm run build` — build client and Nitro server bundles
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint across the repository
- `npm run format` — format files with Prettier
